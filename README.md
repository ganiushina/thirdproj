# HH Dictionary Downloader

Командное Java-приложение, которое скачивает справочники сайта [hh.ru](https://hh.ru) по HTTP API и сохраняет каждый ответ в отдельный файл.

## Сборка
```bash
mvn -DskipTests package
```

## Запуск
```bash
java -jar target/hh-dictionary-downloader-1.0.0.jar \
  --token=12345 \
  --output=responses
```

Дополнительные параметры:
- `--base-url` — базовый URL API (по умолчанию `https://api.hh.ru`).
- `--endpoints` — запятая-разделённый список конечных точек (по умолчанию загружается набор стандартных справочников).
- `--timestamped` — добавляет подпапку с временной меткой в выходном каталоге.

Приложение автоматически обходит иерархический справочник `areas`, скачивая каждую сущность `/areas/{id}` в отдельный файл.
